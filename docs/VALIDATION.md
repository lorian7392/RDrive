- [MCP 14 组](MCP_VALIDATION_0.8.0.json)：81 个工具、31 个只读工具及 8 个资源；既有传输、缓存、同步、事务、取消和路径隔离流程继续通过。

- [并发回执与进程崩溃 7 组](PROVIDER_RECEIPTS_VALIDATION.0.8.0.json)：既有文件/标签安全发布、删除回执丢失后不删除替换文件，以及实际 SIGKILL 后的受保护恢复。

以上操作工作流全部使用临时合成服务和状态目录；最终源码哈希保持冻结。原生 0.8.0/build10 使用同一发布源码编译、通过 ad-hoc 签名核验。实际连接升级结果单独记录于 [原生激活验证](NATIVE_ACTIVATION_0.8.0.json)，不将合成存储上的写入测试描述为真实云盘写入。

Python 语法、Skill 格式和 Git 差异检查通过。使用方式见 [缓存清理与目录管理](CACHE_MANAGEMENT.md)。0.7 的 100 组历史工作流及其功能边界保留在 [0.7 验证记录](VALIDATION_0.7.0.md)，本版不将旧报告计入新的 61 组结果。
