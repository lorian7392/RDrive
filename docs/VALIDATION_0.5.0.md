# RDrive 0.5.0 验证记录

日期：2026-11-10。新增 MCP stdio 接口与三个 AI 操作 Skills；传输、缓存、同步及托管仓库沿用现有实现。本次未重新挂载、修改真实云盘内容或重建原生伴随 App。

141 项 Rust 检查通过：97 项库测试、2 项 CLI 参数回归、1 项 HTTP 缓存、3 项挂载 API、8 项 Smart 日志及 30 项 WebDAV 协议测试。4 项依赖独立 Samba / 原生挂载环境的检查保留忽略状态。详细计数及源码校验见 [CORE_VALIDATION_0.5.0.json](CORE_VALIDATION_0.5.0.json)。

MCP 提供 59 个工具，其中默认开放 23 个查询工具，以及 4 个只读资源。新增检查覆盖协议初始化、参数校验、只读模式、路径范围、写入保护、同步冲突报告、缓存离线读取、队列及托管事务、取消、超时和输入关闭后的清理。黑盒结果及实际 release 文件校验见 [MCP_VALIDATION.json](MCP_VALIDATION.json)。测试服务全部是临时本机 WebDAV 实例，不访问已有连接。

审查修复了历史记录的全局/局部同名参数类型冲突，以及文本工具在输出限额前完整下载大文件的问题。文本读取现在在 GET 前检查受保护版本的大小，下载期间仍由协议实现限制该版本的实际字节数。超过 1 MiB 的文本请求经回归确认没有发出 GET，也未增加临时载荷。

三个 Skill 均通过格式与 UI 元数据验证，安装器经临时目录验证预览、完整及单项安装、拒绝覆盖和符号链接保护。已将三个新技能安装到当前用户的技能目录并核对 8 个文件与仓库源一致；MCP 客户端设置由配置生成器输出，未自动改写现有客户端设置。使用方式见 [MCP 与 Skills](MCP.md)。

0.4.1 的真实 123pan 挂载、Finder 展示、Smart 工作流、加密 SMB 及原生开发包证据保留在 [VALIDATION_0.4.1.md](VALIDATION_0.4.1.md)。这些记录有明确版本，不作为 0.5.0 的再次实测声明。0.5.0 新增内容随 CLI 与 Skills 分发，原生伴随 App 开发包保持 0.4.1。
