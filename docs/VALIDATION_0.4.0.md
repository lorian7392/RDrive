# RDrive 0.4.0 验证记录

日期：2026-11-10；macOS 27.2、Apple Silicon、Rust 1.90。旧版本记录保留在 [0.3.1](VALIDATION_0.3.1.md) 和 [0.3.0](VALIDATION_0.3.0.md)。

## 验证内容

新增缓存模块在下载前持久预留空间，合计命令行载荷与 File Provider 报告的下载副本。测试涵盖容量持久化、拒绝过量下载、LRU、固定文件保护、打开的 FD 租约、重启恢复、账号绑定、原生并发预留、心跳到期，以及流式下载超出声明大小时提前停止写入。回环地址明确直连，避免本机服务流量意外经过系统代理；其他地址仍保留代理支持。

Smart 模式使用持久本地目录索引和不可变编辑快照。真实 HTTP 黑盒测试覆盖离线浏览、源文件删除及 SIGKILL 后恢复、重连自动上传、系统更换请求 UUID 后复用确认回执、连续离线保存、新建文件反复保存、远端冲突导出、文件夹策略继承及新后代、暂停期间状态更新，以及共享容量上限。结果和被测程序 SHA256 见 [SMART_VALIDATION.json](SMART_VALIDATION.json)。

回执测试主动把外部内容或标签修改插入上传确认与最终刷新之间，验证不会把外部版本误记为本次写入回执；还验证独立托管客户端的并发提交、DELETE 后进程崩溃与同路径替代文件，以及标签发布后强制结束进程再恢复确认。连续本地元数据变更只能通过已确认的本客户端回执建立重放链。结果见 [PROVIDER_RECEIPTS_VALIDATION.json](PROVIDER_RECEIPTS_VALIDATION.json)。

SMB 通过独立 Samba 4.21.9 合成服务验证，要求 SMB3 加密。创建文件后不重新下载即可连续修改内容、标签和 #S 属性，保存的强版本与已确认写入对应；外部 SMB 客户端修改后，旧版本覆盖会停止并保留外部内容。结果见 [SMB_PROVIDER_VALIDATION.json](SMB_PROVIDER_VALIDATION.json)。历史的完整十组 SMB 验证保留在 [SMB_VALIDATION.json](SMB_VALIDATION.json)，不冒充此次新增测试。

CLI 九组与 advanced 五组原有流程也已回归，涵盖跨进程 HTTP 断点续传、队列快照、冲突保留、锁、目录同步、版本恢复、并行与限速、属性、托管事务和桥接安全。底层 Rust 单元/HTTP/API 检查及精确数量汇总在 [CORE_VALIDATION.json](CORE_VALIDATION.json)。

## 原生验证

13 组原生宿主测试及 11 组真实 File Provider 工作流通过。Smart 视图的菜单、状态标记和详情窗口已实际显示；独立 FinderSync 菜单在普通测试目录显示，其独立角标仍未确认。构建、签名、系统注册、真实占位文件、菜单/状态显示和容量回收分别核对，细节见 [MACOS_INTEGRATION.md](MACOS_INTEGRATION.md) 与 `macos/build/` 的原生验证报告。界面显示以实际 Finder 观察为依据，不以编译或注册成功代替。

## 范围与边界

新增写入测试仅使用临时本机 WebDAV 和 Samba 服务、合成文件与测试域。没有向真实 123 云盘写入、重命名或删除文件；此前的原生 WebDAV 挂载仍保留。原账户挂载成功、代理路由修复属于 0.3.1 的既有验证，详见历史记录。

清洁缓存上限不包含未上传修改、恢复快照、传输临时副本或系统开销，不是磁盘分区配额。原生内容通过系统 eviction 接口回收，系统拒绝回收的文件不会被截断或删除。固定和未确认修改优先保留，容量不足时拒绝新预留。

普通 WebDAV/SMB 的文件与属性记录分步发布；托管仓库通过单次快照提交提供合作客户端之间的原子视图。服务器断电、服务端实现缺陷、非合作客户端修改内部仓库不在保证范围。

原生包仍为 ad-hoc 开发签名，没有生产开发者签名或公证。不同集成方式的 UI 验证范围按原生说明单独列出。
